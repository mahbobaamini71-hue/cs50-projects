# CS50P: Cookie Jar / Keksdose

A simple Python class for a Cookie Jar, created as part of CS50P.
Eine einfache Python-Klasse für eine Keksdose, erstellt als Teil von CS50P.


### Was ist das?
Dies ist eine Klasse (`Jar`), die eine Keksdose simuliert. Man kann Kekse hinzufügen oder herausnehmen. Die Klasse verhindert, dass man zu viele Kekse hinzufügt oder welche nimmt, die nicht da sind.

### Wie benutzt man es?
Da es keine `main`-Funktion gibt, testet man die Klasse mit `pytest`.

pytest test_jar.py
