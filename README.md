# CS50P Projects / CS50P Projekte

Dieses Repository enthält zwei Python-Projekte aus dem CS50P-Kurs.
This repository contains two Python projects from the CS50P course.

---------------

## 🇩🇪 Deutsch 

### 1. Keksdose (`jar.py` & `test_jar.py`)
Eine Klasse für eine Keksdose. Man kann Kekse hinzufügen oder herausnehmen. Die Klasse verhindert Fehler (z.B. zu viele Kekse). Die Datei `test_jar.py` testet, ob alles richtig funktioniert.
**Testen:** `pytest test_jar.py`

### 2. Tankanzeige (`fuel.py`)
Ein Programm, das einen Bruch (wie 1/2) in Prozent umrechnet. Es prüft die Eingabe und stürzt bei Fehlern (wie 1/0) nicht ab, sondern fragt noch einmal.
**Starten:** `python3 fuel.py`

--------------------

## 🇬🇧 English 

### 1. Cookie Jar (`jar.py` & `test_jar.py`)
A class for a cookie jar. You can add or remove cookies. The class prevents mistakes (like adding too many cookies). The `test_jar.py` file tests if everything works correctly.
**Test:** `pytest test_jar.py`

### 2. Fuel Gauge (`fuel.py`)
A program that converts a fraction (like 1/2) into a percentage. It checks the input and does not crash on errors (like 1/0); it just asks again.
**Run:** `python3 fuel.py`
